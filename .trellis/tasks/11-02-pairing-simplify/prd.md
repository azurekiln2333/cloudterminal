# 配对简化(账号下绑定 + 备选方式)
前置:`11-02-account-auth`。
## Requirements
- 主路径是账号登录(见 account-auth),不再要求用户理解“配对”
- 备选(访客 / 无账号场景),统一入口“添加电脑”:扫码、短码、局域网自动发现并存,界面只突出最快一项
- 短码内嵌服务器信息,手机只输一个码;手工填写收进“高级”
- 绑定走现有 `pair_code` 同意机制并写入账号绑定;码一次性、10 分钟有效,二维码不含长期密钥
- Windows 配对页改为“添加手机/共享”,不再是首次使用的必经页面
## Acceptance Criteria
- [ ] 扫码 / 短码 / 局域网发现各自一步完成绑定
- [ ] 过期、重复使用、错误码提示明确
- [ ] Dart 与 Node 测试通过
